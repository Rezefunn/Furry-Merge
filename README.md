# Furry-Merge · 合成大福瑞

> 团队作品 —— 一款「合成大西瓜」玩法的休闲合成游戏，用可爱的毛茸茸小动物取代水果，通过弹弓发射、同类相撞合成，好玩易上手、可爱又治愈。

---

## 项目简介

这是一款 2D 休闲合成游戏：玩家用弹弓把动物发射进容器，**同等级的动物碰撞后会合成更高级的动物**，从老鼠一路合成到龙。动物堆叠越过红线则游戏结束，合成等级越高得分越高。

- **玩法内核**：同类碰撞合成 + 6 级进化链
- **操作手感**：弹弓拖拽瞄准，带实时预测轨迹线与橡皮筋回弹
- **物理仿真**：发射后的速度衰减（阻尼），模拟真实空气阻力

---

## 核心玩法

| 模块 | 说明 |
|------|------|
| 弹弓发射 | 拖拽动物瞄准，松开发射，带预测轨迹线 |
| 合成进化 | 同类动物碰撞合成下一级，共 6 个等级 |
| 进化链 | 老鼠 → 兔子 → 绵羊 → 狗 → 老虎 → 龙 |
| 游戏结束 | 动物堆叠越过红线即告负 |
| 计分系统 | 合成得分随等级指数增长，最高分持久化 |
| 音效 | 发射音效、失败音效、BGM 淡入淡出 |

## 技术栈

**引擎与语言**
- Unity（URP 渲染管线）
- C#

**游戏框架 / 架构**
- 工厂模式（`AnimalFactory`）— 动物创建与进化映射
- 对象池（`EffectManager`）— 合成特效复用
- 单例管理器 — `GameManager` / `ScoreManager` / `AnimalManager` / `SlingshotController` 等
- 事件 / 委托 — 游戏开始、结束、重玩等状态通知

**第三方插件与系统**
- **Unity 2D Physics** — `Rigidbody2D` / `CircleCollider2D` / 连续碰撞检测
- **TextMesh Pro** — 分数与 UI 文字渲染
- **Unity Audio Mixer** — 音频分组（Master / BGM / Effect）与音量控制

## 系统设计亮点

### 1. 合成玩法核心

动物的进化关系通过工厂模式集中管理（`evolutionMap`），同类碰撞后自动生成下一级动物，并配合缩放过渡动画与合成特效，让合成过程流畅且有反馈。最高等级动物（龙）不再继续进化。

### 2. 弹弓瞄准系统

使用 `LineRenderer` 绘制皮筋，瞄准时通过**物理模拟实时预测弹道**：在预测中叠加了速度衰减、重力，甚至墙壁反弹（`RaycastHit2D` 反射），让玩家在松手前就能看清动物的落点。

### 3. 物理仿真

动物发射后速度按指数衰减（`exp(-t/decayTime)`），模拟空气阻力的阻尼效果；结合 2D 连续碰撞检测（`CollisionDetectionMode2D.Continuous`），避免高速下的穿透，保证碰撞合成稳定。

### 4. 特效对象池

合成特效按动物等级分组缓存（对象池），特效播放完毕后回收复用，避免频繁 `Instantiate` / `Destroy` 带来的性能开销。

### 5. 多平台适配

- **输入**：同时支持鼠标拖拽与触摸滑动
- **存档**：针对 WebGL / Android / iOS / PC 平台分别处理玩家标识（UUID），最高分通过 `PlayerPrefs` 持久化

### 6. 音频系统

通过 Unity Audio Mixer 将音频划分为 Master / BGM / Effect 三组，实现主音量、背景音乐、音效的独立调节；游戏失败时 BGM 平滑淡出后淡入，提升氛围体验。
